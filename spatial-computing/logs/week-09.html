Week 09 Spatial Computing Research Log

Dates

April 25, 2026 - April 27, 2026

Spatial-State Manager Design

I translated the persistent-state idea into a clearer software design. The Vision Pro application would need to retain reconstruction-derived geometry, update timestamps, and simplified spatial regions that could later be queried by pathfinding algorithms.

Instead of treating every incoming update as equally important, the system should filter and preserve changes that affect decision-relevant structure. This separates raw scene input from the stable model that the algorithms actually use.

Connecting Offline and Live Experiments

I reviewed how the Scaniverse workflow converted a finished point cloud into a graph and compared it with the needs of the live application. The offline experiment builds from a complete dataset. The live system must build and revise its model gradually.

This confirmed that the offline graph remains a useful controlled baseline, while the live system introduces additional variables: update timing, model stability, and the conditions that should trigger recomputation.

Result

By the end of this period, the persistent-state layer had a clearer purpose, a clearer set of stored information, and a stronger relationship to the earlier graph experiments.
